# Sample Data Folder

This folder contains sample financial PDF reports for demonstration purposes.

## Purpose

- **Demo Mode**: Allows users to test the application without uploading their own files
- **Quick Start**: Get up and running quickly to see the RAG system in action
- **Testing**: Useful for development and testing

## Usage

1. Place your sample PDF financial reports in this folder
2. In the Streamlit app, select "Use Sample Data" from the sidebar
3. Click "🚀 Load Sample Data" to process the documents

## Getting Sample Reports

You can download financial reports from: https://hexaware.com/investors/annual-reports/

## Note

- This folder is not tracked by git (added to `.gitignore`)
- Only PDF files are processed
- Sample files from the original project should be here for demo purposes
